## 📘 About This Lab

This folder contains the C++ source files for **Programming Fundamentals — Lab 04**.

The lab focuses on decision-making statements and conditional logic in C++, including the use of `if`, `if-else`, and nested `if-else` statements.

## 🎯 Learning Objectives

- Understand decision-making in C++ programs.
- Use conditional statements to evaluate conditions.
- Distinguish between positive, negative, and zero values.
- Apply conditional logic to marks and grading.
- Use nested `if-else` statements to compare numbers.
- Compile, run, and test C++ programs in GitHub Codespaces.

## ▶️ How to Compile and Run

Open the terminal in GitHub Codespaces and navigate to the source-code folder.

Example for Task 01:

```bash
cd Lab-04/Source-Code
g++ Task-01-Positive-or-Negative.cpp -o task01
./task01
```

To run another task, replace the source filename and output name with the relevant file.
