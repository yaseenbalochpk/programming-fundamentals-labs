## 📘 About This Lab

This repository folder contains the source code and home-task programs for **Programming Fundamentals — Lab 03**.

The lab focuses on C++ input statements, expression evaluation, automatic type conversion, type casting, and random number generation.

## 🎯 Learning Objectives

- Understand C++ input statements using `cin`.
- Evaluate arithmetic expressions using operator precedence.
- Understand automatic data type conversion.
- Learn how assignment affects values of different data types.
- Apply type casting to avoid integer division.
- Use random numbers to create a simple Math Tutor program.
- Practice writing, compiling, running, and debugging C++ programs.

## ▶️ How to Compile and Run

Open the terminal in GitHub Codespaces and navigate to the relevant folder.

Example for Task 01:

```bash
cd Lab-03/Source-Code
g++ Task-01-Input-Statement.cpp -o task01
./task01
```

For another task, replace the source filename and output name accordingly.
