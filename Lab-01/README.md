5. Development Environment

The programs are written in C++ and can be compiled using the GNU C++ compiler (g++).

Recommended tools:

* GitHub Codespaces or a Linux terminal
* GNU C++ compiler (g++)
* GitHub repository for source code management

Check whether the compiler is available:

g++ --version

6. How to Compile and Run the Programs

Open the terminal in the repository’s root directory.

Task 01

g++ Lab-01/Source-Code/Lab-01-Task-01.cpp -o task1
./task1

Task 02

g++ Lab-01/Source-Code/Lab-01-Task-02.cpp -o task2
./task2

Task 03

g++ Lab-01/Source-Code/Lab-01-Task-03.cpp -o task3
./task3

How it works:

1. g++ compiles the C++ source file.
2. The -o option specifies the name of the executable program.
3. ./task1, ./task2, or ./task3 runs the compiled program on Linux-based environments.

If compilation reports an error, check the filename, file path, and source code before running the program.
