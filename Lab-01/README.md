## ▶️ How to Compile and Run

Open the terminal in GitHub Codespaces and navigate to the source-code folder.

Example:

```bash
cd Lab-01/Source-Code
g++ Task-01.cpp -o task01
./task01
```

Replace the filename with the actual source file you want to compile and run.
