## 3. Lab Objectives

The objectives of this laboratory are to:

- Understand fundamental C++ data types and variables.
- Learn variable declaration and initialization.
- Understand constants and identifiers.
- Practice C++ escape sequences.
- Apply fundamental arithmetic operators.
- Write, compile, and execute C++ programs.
- Develop logical thinking and problem-solving skills.

## 4. Laboratory Tasks

### Task 01 — Character Variables

Write and execute the three C++ programs provided in the laboratory manual and observe their outputs.

### Task 02 — Arithmetic Operations

Accept two integers from the user and perform the required arithmetic operations:

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)

Display the results on the screen.

### Task 03 — Program Output

Analyze the C++ program provided in the laboratory manual and determine its output.

### Task 04 — Distance Between Two Points

Write a C++ program to calculate the distance between two points using the given formula:

`d = sqrt((x2 - x1)^2 + (y2 - y1)^2)`

The coordinates `x1`, `y1`, `x2`, and `y2` are double values.

### Task 05 — Area Calculations

Write programs to calculate the areas of the following shapes:

1. Circle: `Area = PI * r * r`
2. Rectangle: `Area = length * width`
3. Triangle: `Area = base * height * 0.5`

### Task 06 — Total Purchase and Sales Tax

Write a program that stores the prices of five items in five variables and calculates:

- Individual item prices
- Subtotal
- Sales tax at 6%
- Final total amount

The item prices provided in the laboratory manual are:

| Item | Price |
|---|---:|
| Item 1 | $12.95 |
| Item 2 | $24.95 |
| Item 3 | $6.95 |
| Item 4 | $14.95 |
| Item 5 | $3.95 |

### Bonus Task — Break Number

Write a program that accepts a five-digit integer and separates it into individual digits, displaying the digits with three spaces between them.

### Home Task 01 — Exchange Variables

Write a program that reads two variables and swaps their values.

For example, if `var1 = 10` and `var2 = 20`, the program should exchange their values so that `var1 = 20` and `var2 = 10`.

### Home Task 02 — Make Upper

Write a program that accepts a lowercase English alphabet character and converts it into its uppercase equivalent using ASCII.

For example:

- Input: `a`
- Output: `A`
